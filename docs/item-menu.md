# SFC版Wizardry Vのアイテム編集

GBWizの最新仕様に合わせた、Windows・Android共通の左右２人式エディター。
１人以上の有効なパーティーと原作の入力待ちを条件とする。
場所の許可リストは設けず、戦闘エンジンの呼出スタックと編集中のデータ転送を除外する。

## データと更新

- パーティー：WRAM `0xDB` が人数、`0xDC` から登録番号。
- 人物：WRAM `0x1000 + 登録番号 * 0x80`。
- 所持品：`+0x43` に状態８枠、`+0x4B` に番号８枠、`+0x53` に所持数。
- 状態：`0x80` 装備、`0x40` 呪い、`0x20` 未識別。その他のビットも受け渡し・並べ替え時に保持。
- アイテム表：ROM `03:BB71`、136件、38バイト単位。名前・装備区分・職業条件は実行中ROMを参照。
- 表示：アイテム名と人物名は原作のVRAMフォントを使用。一般の操作文はOSの日本語フォント。
- 装備：原作 `00:9F69` の職業・属性・呪い判定に従う。SPの使用は実行しない。
- 能力再計算：原作 `00:9FA2` を一時的に実行し、AC・所持効果・耐性の結果だけ取得。直後にCPU・APU・WRAM・SRAMを編集前の状態へ復元し、人物レコードだけ反映する。
- 保存：編集前ステートを別ファイルへ保存し、人物チェックサムとSRAMの正副２面を更新。複数人の編集も保存失敗時は全体を戻す。

ROM・セーブ・ステート・フォント画像はリポジトリへ追加しない。

## 確認

`WiizV.exe --smoke --item-check <ROM> --data-dir <空の検証フォルダー> --frames 900`
で、酒場・探索の使用可否、装備と原作AC再計算、状態保持、受け渡し、並べ替え、
削除確認、一括処理、正副SRAM、チェックサム、保存失敗時の復元、戦闘中の禁止を確認する。
検証フォルダーへ画面と結果を出力する。Android実機操作は未確認。
