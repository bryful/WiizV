# マップの踏破表示

対応する日本版ROMについて、原作の踏破情報を読み取り専用で表示する。独自の記録やセーブ形式の変更は行わない。

- WRAM `7E:DC00–DFFF` の1024バイト。各バイトのbit 0–7がB1–B8。
- インデックスは `区画番号 * 64 + localY * 8 + localX`。区画原点はROMのマップ区画定義を使う。壁配列のオフセットと上下反転は使わない。
- `$05:800F–8039` が現在マスのビットを立てる。区画番号と区画内XYは `$05:A86A` の検索で決まる。
- `$00:B92E–B939` がWRAMからSRAM `70:1900–1CFF` に保存し、`$00:B9CF–B9DA` が逆方向に読み込む。
- 表示はWRAMを都度参照するため、通常セーブの読込、ステート復元、新規ゲームに原作どおり追従する。

緑は踏破済み、暗色は未踏破、水色は現在地、黄色の枠は移動先。表示中の階層について踏破済みマス数と全マス数を表示する。B777区画は原作と同じB8の踏破ビットを使う。

`tools/check-movement.ps1` で全8階層の区画インデックス、実移動後の踏破、ステート復元を確認する。踏破ビットは移動先の描画・マス処理が進んでから更新されるため、到着直後に即更新されるとは限らない。
